05 / API–Barrier–Delivery System Logic

1 · API

GHK-Cu เป็น water-soluble peptide; มุ่งให้ถึง dermis [Introduction]

2 · Problem

ผ่าน epidermis ได้ยาก; ปัญหารองคือความไม่คงตัวและ protease degradation [Introduction]

3 · Barrier

stratum corneum/epidermis และ enzymatic environment; ยังไม่ได้พิสูจน์เส้นทางผ่าน [Introduction; §2.4, §2.6]

4 · Delivery system

glycerol-modified nanoliposome, 93.3 ± 2.8 nm, EE 64.3% [§3.1]

5 · Expected mechanism

ผู้วิจัยเสนอการห่อหุ้มช่วยปกป้องและชะลอ release; ความยืดหยุ่น/การผ่านผิวของ carrier ยังเป็นคำอธิบายที่ไม่ได้วัดโดยตรง [Introduction; §3.1–3.2]

6 · Experimental evidence

release ช้าลง, degradation ลดลง, receptor endpoint เพิ่ม; ยังไม่มี layer deposition หรือ carrier tracking [Fig. 1c–e]

การวิเคราะห์: Logic chain แข็งแรงระดับปานกลางในส่วน “ปกป้อง peptide และเปลี่ยน release” แต่ยังอ่อนในส่วน “carrier ผ่าน barrier ไปถึง dermis แล้วทำให้เกิดผลทางชีวภาพ” เพราะ skin experiment กับ cell experiment เป็นคนละชุด ไม่ได้ทดสอบฤทธิ์หลังการนำส่งผ่านผิว

10 / จุดแข็งที่ใช้ในการนำเสนอ

โจทย์ API ชัด

ระบุการผ่าน epidermis ยากและ enzyme susceptibility → เชื่อมเหตุผลเลือก carrier ได้ → ทำให้ประเมินว่าการทดลองตอบปัญหาจริงหรือไม่ [Introduction]

มี free-drug comparator

เปรียบเทียบ LP กับ free GHK-Cu โดย release ระบุความเข้มข้นเท่ากัน → มี baseline ของสาร → รองรับการเปรียบเทียบภายใต้เงื่อนไขที่รายงาน แม้ยังขาด matched vehicle [§2.5–2.6]

มี delivery endpoints หลายแบบ

วัด release, degradation และ skin permeation → เห็นคุณสมบัติคนละด้าน → ไม่อาศัย cellular efficacy อย่างเดียวตัดสินระบบ [Fig. 1c–e]

มีข้อมูลเลือกสูตรและการเปลี่ยนตามเวลา

DLS/TEM/EE และ Table 1 → ตรวจขนาด/การกระจายและความเปลี่ยนแปลง 90 วันได้ → มีฐานวิจารณ์เหตุผลเลือกสูตรจากข้อมูลจริง [§3.1; Fig. 1a; Table 1]

มี functional และ molecular readouts

ROS, migration, apoptosis และ qPCR → เปรียบเทียบการเปลี่ยนแปลงเซลล์หลายด้าน → เพิ่มหลักฐานประกอบฤทธิ์ระดับเซลล์ แต่ยังไม่พิสูจน์ causal pathway [Figs. 2–5]

11 / ข้อจำกัดที่เปลี่ยนการตีความ

1. Target-site delivery ยังไม่ถูกวัด

ไม่มี skin-layer deposition → เป้าหมายคือ dermis แต่ endpoint อยู่ใน receptor → ยังสรุปว่ามีสารออกฤทธิ์ในชั้นเป้าหมายเพิ่มไม่ได้ → เพิ่มการแยกชั้นผิวและ mass balance [Introduction; §2.6; Fig. 1e]

2. Franz method รายงานไม่ครบ

ขาด area, receptor volume, integrity และ donor dose/area → ตรวจการทำซ้ำและ confounding ไม่ได้ → ความมั่นใจต่อขนาด enhancement ลดลง → รายงานวิธีครบและวัด sink/integrity พร้อม assay validation [§2.6]

3. แยก carrier effect จาก vehicle ไม่ได้

มี free drug แต่ไม่มี matched vehicle ใน permeation → polyol/vehicle ต่างกันอาจเกี่ยวข้อง → ยังยก enhancement ให้ rigid-flexible vesicle โดยตรงไม่ได้ → เพิ่ม free drug ใน vehicle เดียวกันและ conventional liposome comparator [§2.2, §2.6; Fig. 1]

4. Release อาจมีข้อจำกัดจาก membrane

dialysis เป็นอีก barrier และไม่มี membrane recovery/kinetic validation → apparent release อาจไม่ได้สะท้อน carrier อย่างเดียว → ข้อสรุป sustained release ยังมีขอบเขต → ตรวจ free-drug transport, membrane binding, sink และ mass balance [§2.5; Fig. 1c]

5. หน่วยและตัวเลขต้องตรวจย้อนกลับ

หน่วย permeation ในข้อความ/ภาพไม่ตรง; release endpoint ไม่สอดคล้องกับภาพโดยประมาณ; EE นิยามสลับ → กระทบการคำนวณและ reproducibility → ยังใช้ค่าต่อโดยไม่ตรวจไม่ได้ → ขอ raw data และยืนยันสูตร/หน่วย ไม่แก้เอง [§2.3, §3.2; Fig. 1]

6. ความคงตัวและความปลอดภัยสรุปกว้าง

Table 1 เป็นขนาด/PDI; LP viability 34.8% ที่ 200 µg/mL และหน่วย Methods ขัดกับ Results → ยังรับรอง stable/non-toxic ทั่วไปไม่ได้ → จำกัดข้อสรุปตามเงื่อนไข และเพิ่ม chemical stability/irritation study [§2.7, §3.3; Table 1; Conclusion]

7. กลไกเซลล์ยังเป็นความสัมพันธ์

qPCR และ functional readouts ไม่มี pathway intervention → ยังไม่ยืนยันว่า Nrf2/SIRT1 เป็นสาเหตุของผล → ใช้คำว่าเกี่ยวข้อง/สอดคล้อง และเพิ่ม protein/activity หรือ inhibitor/knockdown; ตรวจ PGE2-related target จาก primer [§2.12; Figs. 3–5]

8. เอกสารประกอบขาดและบางวิธีไม่ครบ

Table S1–S3 และ Fig. S1–S2 ไม่ได้แนบ; LPS/NO methods ใน main text ไม่ครบ → ตรวจสูตร primer และ safety curve ไม่ได้ทั้งหมด → รายงานนี้เป็นการประเมิน main paper → ขอ supplementary ก่อนสรุปรายละเอียดเหล่านี้ในการนำเสนอ [§2.2, §2.12, §3.1, §3.3, §3.7; Appendix A]

13 / Cosmetics & Topical Application

Potential advantages

ผู้วิจัยรายงาน enzyme protection, release ที่ช้าลง และผลต่อ oxidative/inflammatory responses ใน HaCaT จึงมีฐานสำหรับพัฒนางาน topical ต่อ [Fig. 1c–e; Figs. 3–5]

Practical concerns

ใช้ high-pressure homogenization 1000 bar จำนวน 4 รอบ และต้องคุมอุณหภูมิระหว่างเตรียม; พบ cytotoxicity ที่ความเข้มข้นสูง ความเข้มข้นที่ใช้ในผลิตภัณฑ์จริงจึงยังสรุปไม่ได้ [§2.2; §3.3]

Evidence gaps

ไม่พบข้อมูลใน paper: irritation/sensitization, การใช้ซ้ำในคน, preservative compatibility, finished-product stability, skin feel, scale-up yield, ต้นทุนจริง และข้อกำกับผลิตภัณฑ์ ไม่ใช้คำกล่าว cost-effective แทนข้อมูลต้นทุน [Conclusion]

Overall applicability

การประเมิน: เหมาะเป็น formulation proof of concept ระดับห้องทดลอง ยังไม่ใช่หลักฐานประสิทธิผลหรือความปลอดภัยของเครื่องสำอางสำเร็จรูป การผ่านผิวเพิ่มต้องประเมินร่วมกับการคงอยู่ในชั้นเป้าหมาย [§2.6; §3.3; Table 1]
